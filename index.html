Tutorial Penggunaan Aplikasi

📊 Panduan Admin

1. Dashboard Admin

Melihat ringkasan data santri, guru, dan status pembayaran SPP. Semua statistik penting ditampilkan dalam satu layar.

2. Kelola Data Santri

Tambah, edit, atau hapus data santri. Setiap santri memiliki nomor induk unik, username dan password untuk login.

3. Pengaturan Nominal Pembayaran

Atur nominal SPP bulanan dan daftar ulang. Nominal yang diset akan berlaku untuk semua santri dan terintegrasi dengan pembayaran mereka.

4. Kelola Pembayaran

Pantau pembayaran SPP bulanan dan daftar ulang setiap santri. Ubah status pembayaran dan hitung kekurangan dengan mudah.

5. Kelola Data Guru

Tambah guru, atur santri yang diampu, dan kelola akun login guru di sistem.

👩‍🏫 Panduan Guru/Musyrifah

1. Dashboard Guru

Lihat jumlah santri yang Anda ampu dan ringkasan aktivitas absensi hari ini.

2. Input Absensi Kegiatan

Catat kehadiran santri dalam kegiatan rutin (ziyadah, takror, murojaah, madin, dll). Pilih santri, tanggal, dan checklist kegiatan yang diikuti.

3. Input Perolehan Hafalan

Catat progres hafalan ziyadah dan muroja'ah setiap santri setiap harinya.

4. Catat Pelanggaran

Dokumentasikan setiap pelanggaran santri dengan tanggal dan keterangan lengkap untuk arsip.

5. Catatan Guru/Musyrifah

Tulis catatan perkembangan santri, karakter, atau hal penting lainnya untuk komunikasi dengan wali santri.

👧 Panduan Wali Santri

1. Info Santri

Lihat data lengkap santri (nama, kamar, kelas, alamat, orang tua, nomor kontak).

2. Cek Pembayaran

Monitor status pembayaran SPP bulanan dan daftar ulang. Lihat nominal, jumlah yang sudah dibayar, dan sisanya.

3. Lihat Absensi

Pantau kehadiran santri dalam kegiatan-kegiatan pesantren (dalam 7 hari terakhir).

4. Perkembangan Hafalan

Lihat progres hafalan santri dari catatan guru (ziyadah dan muroja'ah).

5. Catatan & Pelanggaran

Baca catatan guru tentang perkembangan santri dan riwayat pelanggaran (jika ada).

Tips Penting

  • • Pastikan username dan password Anda aman dan tidak dibagikan
  • • Selalu keluar (logout) setelah selesai menggunakan aplikasi
  • • Data disimpan otomatis di sistem, jangan perlu khawatir
  • • Hubungi admin jika ada masalah atau pertanyaan teknis
